# pam: Presence-Absence Matrix Construction from Species Range Maps

Constructs geographic presence-absence matrices (PAMs) from species
range polygons stored as 'terra' SpatVector objects. Rasterizes vector
geometries onto a user-defined grid and pivots the result into a
sites-by-species binary matrix suitable for biodiversity analyses.
Includes convenience functions to retrieve example mammal range data and
WorldClim environmental layers projected to two dimensions via Principal
Component Analysis.
